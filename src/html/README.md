# HTML Templates

Each page is a standalone document. Shared parts are included via `@@include` with parameters. Paths are relative to `src/html/`. Pages start with `<html lang="@@lang">` — the language comes from `site.lang` in `project.config.js`.

## Structure

```
html/
├── layouts/
│   ├── _head.html         # <head> meta, OG tags, styles
│   ├── _header.html       # Site header
│   ├── _footer.html       # Site footer
│   ├── _modals.html       # Modal wrapper + script
│   └── _tailwind-cdn.html # Tailwind CDN dev mode (prod builds only)
├── components/
│   ├── _icon.html         # SVG sprite icon
│   ├── _picture.html      # Responsive image (webp + fallback)
│   └── demo.html          # Demo section (pnpm clean:demo)
└── pages/
    ├── index.html         # → dist/index.html
    ├── template.html      # → dist/template.html (starter page)
    └── 404.html           # → dist/404.html (noindex)
```

> Keep pages flat (directly in `pages/`) — layouts use relative `./styles/...` paths that break one level deep.

## Creating a Page

Copy `template.html`. Every page passes params to `_head.html`:

```html
<!-- prettier-ignore -->
@@include('layouts/_head.html', {
  "title": "About",
  "description": "About page description",
  "image": "./assets/img/previews/global.webp"
})
```

| Parameter     | Used for                                                            |
| ------------- | ------------------------------------------------------------------- |
| `title`       | `<title>` + OG/Twitter title                                        |
| `description` | Meta + OG/Twitter description                                       |
| `image`       | OG/Twitter Card preview — relative path, made absolute by the build |

The build also emits `<link rel="canonical">` and `og:url` from `SITE_URL` + the page path (`__PAGE_URL__` placeholder in `_head.html`).

## Icons

Add an SVG to `src/assets/sprites/`, then:

```html
@@include('components/_icon.html', {"name": "arrow-right"})
```

## Responsive Images

All params required; the `.webp` sibling is generated by the build:

```html
@@include('components/_picture.html', { "src": "./assets/img/photo", "ext": "jpg", "alt": "…", "class": "", "loading":
"lazy", "width": "1200", "height": "675" })
```

## Context Variables (`@@if`)

| Variable      | Value                                         |
| ------------- | --------------------------------------------- |
| `tailwind`    | Tailwind pipeline active                      |
| `tailwindCdn` | Tailwind active + production/handoff build    |
| `criticalCss` | `optimization.criticalCSS` enabled            |
| `lang`        | `site.lang` from project.config.js (`@@lang`) |
| `siteUrl`     | `site.url` (SITE_URL) — for absolute links    |

Used by `_head.html` — vanilla projects emit nothing.

## Vendor Libraries

Classic tags **before** the module entry (globals like `window.Swiper`):

```html
<link rel="stylesheet" href="./styles/vendor/swiper.min.css" />
<script src="./scripts/vendor/swiper-bundle.min.js"></script>
<script src="./scripts/app.js" type="module"></script>
```
